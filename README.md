# بوابة الطالب — الإصدار الثاني

## ماذا تغير؟
تم تحويل مساعد الأسئلة من Prototype محلي إلى واجهة أمامية تتصل بـ Backend حقيقي عبر `/api/chat`.

الـBackend:
- يحافظ على مفتاح OpenAI بعيدًا عن المتصفح.
- يرسل السؤال للنموذج مع قاعدة المعرفة الموجودة في `knowledge.json`.
- يفرض تعليمات تمنع اختراع معلومات خارج قاعدة المعرفة.
- يمكن تغيير النموذج من متغير `OPENAI_MODEL`.

## التشغيل محليًا
1. ثبّت Node.js حديثًا.
2. اضبط متغير البيئة `OPENAI_API_KEY`.
3. شغّل:
   `npm start`
4. افتح:
   `http://localhost:3000`

## مهم
هذه النسخة تستخدم OpenAI API، وبالتالي تحتاج مفتاح API وحساب API صالحًا، وقد تترتب تكلفة استخدام حسب النموذج والاستهلاك.
لا تضع مفتاح API في `app.js` أو `index.html` أو أي ملف يصل للمتصفح.

## قبل النشر العام
- إضافة rate limiting.
- تسجيل أخطاء بدون حفظ أسئلة حساسة.
- إضافة لوحة إدارة لتحديث قاعدة المعرفة.
- مراجعة جميع معلومات الكلية من المصادر الرسمية قبل اعتمادها للطلاب.


## النشر
الملف `render.yaml` و`Dockerfile` مجهزان للنشر على Render.
بعد ربط مستودع المشروع:
- أضف `OPENAI_API_KEY` كـ Secret/Environment Variable في الاستضافة.
- اترك `OPENAI_MODEL` على `gpt-5.6-luna` أو غيّره من إعدادات الخدمة.
- Health check: `/api/health`.

لا تضع مفتاح API داخل Git أو داخل ملفات HTML/JS.
